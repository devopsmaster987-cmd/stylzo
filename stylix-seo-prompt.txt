# Stylix SEO Landing Pages, Keyword Dashboard & Emoji Optimization — Master Prompt

You are working on **Stylix**, an existing server-rendered fancy text generator built with Node.js, Express, EJS, CSS, and vanilla JavaScript. The project does not use a SPA or React, except for one lazy-loaded 3D hero.

Your task is to inspect the actual project and supplied keyword list, then implement a production-ready SEO keyword system with a **left-side keyword dashboard**, relevant landing pages, emoji-wrapped keyword variations, SEO metadata, and automated tests.

Do not return another conceptual plan. Implement changes directly in the existing codebase.

## STEP 1 — Inspect the existing project

1. Inspect the complete project structure, `package.json`, Express routes, EJS templates, stylesheets, JavaScript, existing generators, sitemap, metadata, and current landing pages.
2. Find and read the complete keyword-list source file. Also use the keyword list supplied in this prompt if it is not stored separately.
3. Identify existing H1, H2, and H3 headings and preserve relevant headings.
4. Identify existing functionality before making changes.
5. Reuse existing templates, layouts, routes, and generator logic wherever possible.
6. Do not migrate to Next.js, React, or another framework.
7. Do not overwrite unrelated files or remove working features.
8. Do not create duplicate routes or landing pages.
9. If a file is missing, create it only when necessary.
10. Before implementation, identify the existing route structure and the best place to integrate the keyword dashboard.
